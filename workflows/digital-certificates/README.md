# Digital Certificate Creation & Validation

Two alternatives for issuing and verifying digital certificates:

- [HTML/CSS PDF generation](./html-pdf/README.md): renders certificates from workflow-managed HTML/CSS.
- [PDF Generator API](./pdf-generator-api/README.md): uses an external reusable PDF template.

Choose the approach that matches your design and integration requirements. Each variant includes its own importable workflow, documentation and assets.
