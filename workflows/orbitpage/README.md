# OrbitPage workflows

n8n templates for managing OrbitPage content and releases. Each folder includes an importable workflow and its setup instructions.

| Workflow | Purpose | Files and setup |
| --- | --- | --- |
| Sync Google Sheets Menus and Price Lists to OrbitPage | Sync approved sheet rows to a native menu section, with previews and email review. | [Folder](./sync-google-sheets-menus-and-price-lists-to-orbitpage/) · [Guide](./sync-google-sheets-menus-and-price-lists-to-orbitpage/README.md) |
| Add New YouTube Videos to OrbitPage | Add new YouTube videos as native players, automatically or after email approval. | [Folder](./add-new-youtube-videos-to-orbitpage/) · [Guide](./add-new-youtube-videos-to-orbitpage/README.md) |
| OrbitPage AI Page Editor | Prepare validated page edits from chat, review previews and approve publication. | [Folder](./orbitpage-ai-page-editor/) · [Guide](./orbitpage-ai-page-editor/README.md) |
| OrbitPage Release Guardian | Monitor saved revisions, verify published pages and request approval for rollback. | [Folder](./orbitpage-release-guardian/) · [Guide](./orbitpage-release-guardian/README.md) |
| Update an OrbitPage Event Before, During and After | Publish approved event phases at one stable URL, with guarded revisions, a durable journal and a reusable local QR. | [Folder](./orbitpage-event-lifecycle/) · [Guide](./orbitpage-event-lifecycle/README.md) |
| Build an OrbitPage Campaign Page with Ad Copy, UTM Links and QR | Review one offer, publish its campaign subpage, verify the result and deliver matching ad copy, UTM links and a local QR. | [Folder](./orbitpage-campaign-launch-kit/) · [Guide](./orbitpage-campaign-launch-kit/README.md) |
| Review OrbitPage Analytics and Approve One CTA Improvement | Send a measured analytics report and optionally review and publish one exact server-previewed CTA title improvement. | [Folder](./orbitpage-analytics-improvement/) · [Guide](./orbitpage-analytics-improvement/README.md) |
