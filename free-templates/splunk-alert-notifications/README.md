# Splunk Security Alert Notifications

Two successive workflow releases:

- [v1 — Email & Telegram alerts](./v1/README.md): webhook-based routing and notifications.
- [v2 — Enrichment & smart notifications](./v2/README.md): adds enrichment, deduplication, severity-based routing and daily digest.

Choose v2 for the extended capabilities or v1 for a simpler deployment. Both remain available as separate importable workflows.
